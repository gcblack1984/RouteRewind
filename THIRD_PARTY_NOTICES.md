# Componenti di terze parti

RouteRewind usa i seguenti componenti, ciascuno con la propria licenza.

| Componente | Uso | Licenza |
| --- | --- | --- |
| Qt for Python (PySide6) | interfaccia e motore web | LGPL v3 |
| Leaflet | mappa interattiva | BSD 2-Clause |
| protomaps-leaflet | mappe offline vettoriali | BSD 3-Clause |
| pdfplumber | lettura PDF | MIT |
| openpyxl | lettura Excel | MIT |
| python-docx | lettura Word | MIT |
| python-dateutil | interpretazione date | Apache 2.0 / BSD |
| xlrd (facoltativo) | vecchi file .xls | BSD |
| PyInstaller (solo build) | creazione exe | GPL v2 con eccezione per i programmi distribuiti |

Dati e mappe:

- Dati © OpenStreetMap contributors, licenza ODbL (anche nelle mappe offline Protomaps).
- Mappe di base © CARTO; immagini satellitari © Esri e fornitori.

PySide6 è distribuito come libreria collegata dinamicamente (cartella dell'exe), come
consentito dalla LGPL: l'utente può sostituirne i file con un'altra versione compatibile.
